DAUDGPT PRO — Local AI Chat Interface

1. Extract this folder.
2. Open CMD in the extracted DaudGPT_Pro folder.
3. Run: uvicorn main:app --reload
4. Open: http://127.0.0.1:8000

Ollama must be running and qwen2.5-coder:7b must be installed.
The chat list is kept in browser memory for this session only.
